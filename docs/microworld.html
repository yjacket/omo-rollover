OMO 메인 세션 하나가 서브에이전트를 굴리며 컨텍스트를 키우다가, 예산을 넘으면 확장이 안전한 착륙 지점을 잡아 새 세션으로 넘기는 과정. 예시 수치, 실제 세션 아님.

이벤트 로그

신호 1
message_end

어시스턴트 응답마다 usage 도착. input + cacheRead + cacheWrite가 현재 컨텍스트. 스트리밍 중 값은 무시.

신호 2
wake_source_state

주차된 메인을 깨울 수 있는 것(자식, 터미널 모니터)이 생기거나 끝날 때 즉시 발행. Goal 백스톱이 쓰는 신호를 그대로 구독.

신호 3
agent_settled

재시도·자동압축·큐가 남지 않은 진짜 idle. 자식이 돌아도 뜰 수 있으므로 신호 2와 AND.

레버
tool_call 차단

armed 이후 task_create를 거부. 겹치기 실행에서도 진행 중 자식만 자연 drain되면 합 0에 도달.

토글 실험: 겹치기 실행을 켜고 차단을 끄면 자식 수가 0인 settle 시점이 오지 않아 armed에서 영원히 머무름. 차단을 다시 켜면 가장 오래 걸리는 진행 중 자식 하나만큼 기다린 뒤 착륙. 예산 슬라이더는 트리거 시점만 바꾸고 착륙 규칙은 바꾸지 않음.
